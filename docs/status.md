# 项目定位与验证状态

OmniPost 是基于 `dreammis/social-auto-upload` 二次开发的多平台内容发布工具。项目名称为 OmniPost；Python 包名仍为 `social-auto-upload`，CLI 命令仍为 `sau`。

## 使用入口

| 入口 | 当前定位 | 覆盖范围 |
| --- | --- | --- |
| Web 管理台 | 当前维护和推荐使用的入口 | 账号、素材、创作者中心、发布任务和内容数据 |
| CLI | 保留的兼容入口，未随本次 Web 更新同步维护 | `douyin`、`kuaishou`、`xiaohongshu`、`bilibili`、`tencent` |
| examples | 保留的开发参考，未随本次 Web 更新同步维护 | 含尚未 CLI 化的平台，通常需要修改脚本中的路径和文案 |
| skills | 保留的 CLI 操作参考，未随本次 Web 更新同步维护 | 抖音、快手、小红书、Bilibili 共四个 Skill；视频号暂无独立 Skill |

**本次更新以 Web 界面及其后端流程为主，推荐普通用户使用 Web。** 其他入口未同步维护，不能因为安装成功、帮助可用或示例参数能解析，就认为其平台操作已更新或可用。README 的能力表仅描述 Web，保留的 CLI / examples 能力见各自参考和源码。

## 安装与文档依据

- 完整安装和启动步骤统一放在 [README](../README.md#安装)，[安装说明](./install.md) 负责排障。
- Python 支持范围为 3.10–3.12，推荐 3.12；前端使用 Node.js 22 或 24。
- Python 依赖声明和锁定分别使用 `pyproject.toml`、`uv.lock`；前端使用 `package.json`、`package-lock.json`。
- `requirements.txt` 是 pip 兼容入口，不是另一套依赖清单。当前公开说明以源码安装为准。
- 默认仅本机访问：后端 5409、前端开发服务 5173、构建预览 4173 均绑定 `127.0.0.1`。
- CLI 参数以 `sau_cli.py` 和对应 `--help` 为准；后端接口以 `sau_backend.py` 为准。文档示例中的素材路径、账号名和定时时间需要替换。

## 当前已验证范围

本表记录 2026-11-03 在 Windows、Python 3.12、Node.js 24 环境中的本地检查，后续发布应根据实际结果更新。

| 项目 | 结果 |
| --- | --- |
| 干净源码副本的锁定安装 | Web 完整安装与纯 CLI 安装均通过 |
| 数据库初始化 | 从不同工作目录运行正常；重复执行保留已有账号 |
| CLI 入口 | 帮助可用，解析器提供五个平台入口 |
| 前端 | `npm ci`、生产构建及首页/账号/素材/发布/数据页面检查通过 |
| 本地 API | 账号、素材、账号校验接口和前端代理检查通过 |
| 浏览器 | 系统 Chrome 与 Playwright Chromium 启动通过；本机旧缓存锁问题使用独立缓存验证，设置见安装说明 |
| 监听与跨域 | 三个服务仅绑定本机；本机来源获准跨域，外部来源不获得允许跨域响应头 |
| 自动化测试 | 134 项全部通过；平台流程测试使用替身，不能代替真实账号验证 |

视频号登录测试已补齐页面导航等待的替身方法，并检查等待参数。测试运行仍有百家号选择器转义与抖音调度测试替身的警告，不影响当前测试通过结果；这些检查不代表真实平台发布已实测。

## 尚未实测范围

- 各平台使用真实账号的扫码登录、上传、发布成功判定、定时发布和数据同步。
- macOS、Linux 和 Docker 的完整安装与运行。
- 所有平台后台的当前页面结构、账号权限和风控表现。

README 中的能力标记表示代码提供对应实现，不代表本版本已完成真实账号验证。`dryRun` 或浏览器填表成功也不能等同于发布成功；Bilibili 的 Web 预览不会实际上传。

## 发布范围

开源源码应包含两个锁文件，并排除本地配置、Cookie、数据库、素材、日志、虚拟环境和缓存。`.gitignore` 只影响 Git，直接压缩目录时应使用并检查 `scripts/pack_opensource.py` 的输出。

Skill 分发的当前做法与尚未实现的规划见 [Skill 分发说明](./skill-distribution.md)。
